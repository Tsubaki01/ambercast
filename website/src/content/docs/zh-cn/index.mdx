就像琥珀中封存的昆虫，你测试的意图只需铸造一次便被完整保留 —— 无论表层如何变化。

<CardGrid stagger>
	<Card title="回放零 AI 调用" icon="approve-check">
		生成一次，永久回放。`ambercast run` 会确定性地重放已提交的执行计划 —— 除非某一步的缓存定位缺失，否则不会产生 AI 调用。
	</Card>
	<Card title="类似锁文件的执行计划" icon="document">
		`generate` 会将执行计划和定位缓存写为可被 git diff 的纯 JSON。像对待锁文件一样提交并复核它们。
	</Card>
	<Card title="自我修复" icon="rocket">
		当 UI 发生漂移时，`ambercast heal` 会重新解析、修复或重新生成受影响的计划步骤 —— 并在写入前请求确认。
	</Card>
	<Card title="自带 AI 提供方" icon="setting">
		无需托管凭据。ambercast 驱动你自行安装并完成身份验证的 Claude Code CLI 或 Codex CLI。
	</Card>
</CardGrid>
